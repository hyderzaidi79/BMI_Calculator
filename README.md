# 💪🧮 BMI Calculator - Streamlit App

A simple and visually styled Body Mass Index (BMI) Calculator built using **Streamlit**. Users can input their height and weight to receive an instant BMI value along with a category (underweight, normal, overweight, or obese), all displayed with colorful messages and emojis for a fun and interactive experience!

---

## 🚀 Features

- 📏 Input fields for **height (cm)** and **weight (kg)**
- 📊 Instant BMI calculation with a styled result
- 🎨 Custom-colored category messages:
  - 📉 Underweight
  - 🎊 Normal weight
  - ⚠️ Overweight
  - 🚫 Obese
- 🖼️ Background image for visual enhancement
- 📱 Fully responsive for desktop and mobile users

---

## 📦 Installation

1. Make sure you have **Python 3.7+** installed.
2. Install required package:

```bash
pip install streamlit

    Save the Python script (e.g., bmi_calculator.py).

▶️ Run the App

Use the following command in your terminal:

streamlit run bmi_calculator.py

Your browser will automatically open the app at http://localhost:8501.
📝 Example

    Input: Height = 170 cm, Weight = 65 kg
    Output: BMI = 22.49 → 🎊 You are in the normal weight range.

🧠 BMI Formula
BMI=weight (kg)[height (m)]2
BMI=[height (m)]2weight (kg)​
